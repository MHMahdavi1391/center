# پوشه اسلایدر هاب

عکس و بنر تبلیغ را همین‌جا بگذار. نام فایل مهم نیست و تعداد هم محدود نیست.

- نسبت تصویر: ۲:۱ افقی (مثلاً ۱۶۰۰×۸۰۰ یا ۱۲۰۰×۶۰۰)
- فرمت: jpg، jpeg، png، webp، gif، avif، svg
- بعد از آپلود به همین پوشه در ریپوی center، صفحه اصلی خودش همه‌شان را پخش می‌کند
- هر ۵ ثانیه ورق می‌خورد؛ دکمه‌های کنار و کشیدن انگشت هم عقب و جلو می‌برند

سه فایل svg نمونه را بعد از گذاشتن عکس‌های خودت می‌توانی حذف کنی.
